# CSCI 0320/1340 Notes

Welcome to CSCI 0320/1340! 

This page contains the lecture notes for this course. Some lectures are mainly done via slides, in which case we will link the slides as well.

These notes are meant to be accompanied by the [course live code repository](https://github.com/cs0320/class-livecode), which contains a collection of code examples done in and out of class. The course assumes that students will review the live code. (The end goal is to combine the two into one book, but for now they are separate resources.)

!!! warning "These notes are not final!"
    This outline is subject to change, and notes are often modified in response to TA feedback or student Q&A before class. Some notes will be greyed out and inaccessible in the table of contents.
